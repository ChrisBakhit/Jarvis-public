# Editions

[Jarvis](https://github.com/ChrisBakhit/Jarvis) is the private edition and the source of truth.

Afterwards, Jarvis-public will be a sanitized clone of the private Jarvis edition: the same project content, with credentials, keys, tokens, DPAPI blobs, SSH private keys, credential stores, and other secrets removed. Today's tree in this repository is not that clone yet.

"Everything" means project content. "Secure" means no keys or credentials. A secret removed from a file is not a substitute for reviewing that file before it is published.

Ownership and license for redistribution remain unresolved. The later clone still needs that review before it is treated as a public release. This document assigns no license.

Implementation of the installed house integration remains paused. This document does not authorize recovery.
